# Emoji keys

Every emoji the bot uses lives in `emojis.json`, keyed by a plain name.

- To add or replace one, drop a PNG/GIF named **exactly the key** into `tempassets/` and start the bot. `emojiSync` uploads it and writes the real id into `emojis.json`.
- Entries ending in `:0>` are **placeholders**: not uploaded yet. The bot shows a normal fallback until you add the image.
- Same job, same key: back and forward arrows are `arrow_left` / `arrow_right` everywhere, on/off switches are `toggle_on` / `toggle_off`, success and error are `success` / `error`.
